
# OUTLINE MATERI PEMBELAJARAN

## Materi: Penyajian Data

### 1. Tujuan Pembelajaran
Siswa mampu memahami, membaca, menyajikan, dan menafsirkan data dalam bentuk diagram garis dan diagram lingkaran.

### 2. Pokok Materi
- Pengertian penyajian data
- Penyajian data menggunakan diagram garis
- Penyajian data menggunakan diagram lingkaran
- Membaca dan menafsirkan informasi dari diagram
- Penerapan penyajian data dalam kehidupan sehari-hari

### 3. Contoh Penerapan
- Data jumlah pengunjung perpustakaan.
- Data hasil survei kegiatan olahraga siswa.
- Data pilihan ekstrakurikuler siswa.

### 4. Latihan Mathematical Literacy
- Mathematical Reasoning
- Formulating Situations Mathematically
- Employing Mathematical Concepts, Facts, and Procedures
- Interpreting, Applying, and Evaluating Mathematical Outcomes
